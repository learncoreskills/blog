# Day 3: daily sessions, and a home for this blog

Two new pieces landed today, building on yesterday's v1. First, "daily practice" — logic that
puts together a sensible practice session for a child each day, instead of just handing over
exercises with no structure or pacing.

Second, this blog and the project's specs got a home inside the app itself: a documentation area
where parents and teachers can read what's been built and why, without leaving the app or digging
through GitHub. It's deliberately styled differently from the playful, kid-facing practice
screens, since it's meant for a different audience reading it for a different reason.
