# CLAUDE.md

## This repo is the mandatory third step of every feature

Per the project constitution (`../specs/.specify/memory/constitution.md`, "Development
Workflow"), every feature follows `specs` → `app` → `blog` in order, and is **not considered
complete** until a write-up exists here — this repo is a running, chronological record of
everything shipped in the project, not optional polish.

When implementation work on a feature wraps up (in this session or handed off from one), add a
`YYYY-MM-DD-<slug>-plan-and-implementation.md` post matching the existing posts' format: title
`# Nth feature: <name> — plan + implementation`; sections `## planning`, `## implementation`,
`## verification`; a closing "where things stand" / "next up" paragraph. Look at any existing
file here for the concrete tone and level of detail.
