# CLAUDE.md

## This repo is the mandatory third step of every feature

Per the project constitution (`../specs/.specify/memory/constitution.md`, "Development
Workflow"), every feature follows `specs` → `app` → `blog` in order, and is **not considered
complete** until a write-up exists here — this repo is a running, chronological record of
everything shipped in the project, not optional polish.

## Format: one post per day, story-style

As of 2026-09-14 this blog is **one compact, narrative post per day**, not one technical post per
feature. It's written for a general audience (parents/teachers reading it from inside the app),
not a technical write-up — no section headings, no implementation detail, just what happened that
day and why it matters, in a few short paragraphs.

When implementation work wraps up (in this session or handed off from one): if a post for
today's date (`YYYY-MM-DD-<slug>.md`) already exists, add a short paragraph to it rather than
creating a second file for the same day. Only start a new file when the calendar date changes.
Look at the 2026-09-12/13/14 posts here for the concrete tone and length.
