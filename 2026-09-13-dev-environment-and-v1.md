# Day 2: setting up shop, then shipping v1

With the project structure in place, day two started with getting a real development setup
working: a dedicated VM to build on, Claude Code as the coding assistant, and VS Code as the
editor. Getting that combination running smoothly, rather than building directly on a personal
machine, was the first task of the day.

Once that was sorted, the rest of the day went into putting together an actual first version of
the app. By the end of it, v1 existed: a basic app shell to hold everything together, a first
practice exercise (mental addition) a child can actually try, a way to track how well a child is
progressing on a skill, an engine designed so new exercise types can be added later without
reworking the core, and a first pass at handling accounts and privacy responsibly. Small on their
own, but put together they added up to something a child could actually open and use.
